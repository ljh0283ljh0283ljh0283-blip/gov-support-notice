# 지원사업 공고 모아보기

**공개 페이지: https://ljh0283ljh0283ljh0283-blip.github.io/gov-support-notice/**
(GitHub Actions가 한국시간 평일 오전 8:30에 자동 갱신 · 저장소 Actions 탭 → "지원사업 공고 갱신" → Run workflow 로 즉시 갱신)

경기도경제과학진흥원이 운영하는 **경기기업비서(이지비즈, egbiz.or.kr)** 의 지원사업을
분야별(기술·경영·수출·금융·인력·내수·창업·제도·동반성장·소상공)로 정리해서 보여줍니다.

## 쓰는 법
1. `run.bat` 더블클릭 → `reports\최신_지원사업.html` 이 열립니다.
2. 받고 싶은 분야·키워드는 `config.json` 에서 고칩니다.

## 만들어지는 것
| 파일 | 내용 |
|---|---|
| `reports\최신_지원사업.html` | 항상 최신 리포트 (맞춤 키워드 / 마감 임박 / 분야별 전체, 분야 버튼으로 필터) |
| `reports\지원사업_YYYYMMDD.html` | 날짜별 보관본 |
| `reports\지원사업_YYYYMMDD.csv` | 엑셀로 열 수 있는 목록 |
| `data\seen.json` | 이미 본 공고 기록 (지우면 NEW 표시가 처음부터 다시 계산됨) |

## 자동 실행 (등록 완료)
Windows 작업 스케줄러에 `지원사업공고` 작업으로 등록되어 **평일 아침 8시 30분**에 실행됩니다.
자동 실행 때는 창을 띄우지 않고 파일만 새로 만들며, 실행 기록은 `data\run_log.txt` 에 쌓입니다.
시간을 바꾸거나 끄려면 시작 메뉴 → '작업 스케줄러' → `지원사업공고` 를 여세요.
이 폴더를 다른 곳으로 옮기면 작업 스케줄러의 경로도 같이 바꿔야 합니다.

## 메일로 받기
`config.json` 의 `메일` 항목에서 `보내기` 를 `true` 로, 보내는사람·받는사람을 채우고
비밀번호는 Windows 환경변수 `GOV_MAIL_PASSWORD` 에 넣습니다. (Gmail은 '앱 비밀번호' 사용)
새 공고가 있을 때만 새 공고를 분야별로 정리한 메일이 가고, 전체 리포트가 첨부됩니다.
